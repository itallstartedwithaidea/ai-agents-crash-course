## 🤖 О курсе

**Бесплатный открытый интенсив на 42 страницы** о создании ИИ‑агентов — автор **John Williams**, Senior Paid Media Specialist в [Seer Interactive](https://seerinteractive.com) с 15+ годами опыта и $48M+ управляемых расходов на цифровую рекламу, создатель [googleadsagent.ai](https://googleadsagent.ai).

Каждая идея объясняется простыми аналогиями. Каждый шаг проверяется блоками «Что вы должны увидеть». Каждый день заканчивается играбельной игрой, собранной через prompting на естественном языке. Оформление по APA 7th Edition, 16 формальных источников.

### Новое в v5.0 (март 2026)

- **Интеграция Anthropic Academy** — 13 бесплатных курсов с сертификатами, разбросанных по материалу: Claude 101, Claude Code in Action, курсы MCP, AI Fluency и Agent Skills
- **Интерактивные тесты с вариантами ответов** — 6 оцениваемых тестов (21 вопрос) вместо свободного текста: мгновенная обратная связь и баллы
- **XP и геймификация** — Начисление XP за дни и тесты, уровни от Novice до Master, 6 значков достижений
- **Ежедневные серии** — Заходите каждый день, чтобы растить серию; серии из 3 дней открывают значки
- **Новые продукты** — Claude Code, Claude Cowork (янв. 2026), Agent Skills, обновления MCP

## 🤖 Сквозная линия googleadsagent.ai

[googleadsagent.ai](https://googleadsagent.ai) проходит через курс как **живая эталонная реализация**:

| Компонент | Реализация | День |
|-----------|---------------|-----|
| Мозг | Claude от Anthropic (Opus 4.5 + Sonnet 4.5) | 1 |
| Инструменты | 28 Python API actions с живым доступом к Google Ads API | 2 |
| MCP | Адаптер: `tool_executor.py` | 2 |
| Контекст | Протокол CEP + Session State Manager | 3 |
| Качество | Top-Down Reporting + безопасность записи CONFIRM | 4 |
| Мультиагенты | 🦁 Simba · 🐠 Nemo · ❄️ Elsa · 🧞 Aladdin · 🌊 Moana · 🤖 Baymax | 5 |
| Продакшн | CLI, REST API, Docker, Python SDK | 5 |
