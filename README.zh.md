## 🤖 简介

这是一份**免费、开源、共 42 页**的 AI 智能体速成教材，作者是 **John Williams**——[Seer Interactive](https://seerinteractive.com) 高级付费媒体专家，拥有 15 年以上经验，管理过逾 4800 万美元数字广告支出，也是 [googleadsagent.ai](https://googleadsagent.ai) 的创建者。

每个概念都用通俗类比讲解；每个步骤都配有「你应当看到什么」的核对说明；每一天都会用自然语言提示词完成一款可玩的电子游戏。全文按 APA 第 7 版排版，含 16 条正式参考文献。

### v5.0 更新（2026 年 3 月）

- **接入 Anthropic Academy** — 全文穿插 13 门免费含证书课程，涵盖 Claude 101、Claude Code in Action、MCP 课程、AI Fluency 与 Agent Skills
- **交互式选择题测验** — 6 套计分测验（共 21 题），取代纯文本作答，即时反馈与打分
- **经验值与游戏化** — 完成每日内容与测验可获得 XP，从 Novice 升至 Master，解锁 6 枚成就徽章
- **每日连续学习** — 每天回访累积连续天数；连续 3 天可解锁徽章
- **新产品覆盖** — Claude Code、Claude Cowork（2026 年 1 月）、Agent Skills、MCP 更新
