## 🤖 소개

AI 에이전트 구축을 다루는 **무료 오픈소스 42페이지 크래시 코스**입니다. 저자 **John Williams**는 [Seer Interactive](https://seerinteractive.com)의 Senior Paid Media Specialist로 15년 이상 경험이 있으며 4,800만 달러 이상의 디지털 광고비를 관리했고, [googleadsagent.ai](https://googleadsagent.ai)를 만든 사람입니다.

모든 개념은 이해하기 쉬운 비유로 설명하고, 모든 단계는 “이렇게 보여야 합니다” 안내로 검증합니다. 매일마다 자연어 프롬프팅만으로 만든 플레이 가능한 비디오 게임으로 마무리합니다. APA 제7판 형식과 정식 참고문헌 16건을 따릅니다.

### v5.0의 새로운 점(2026년 3월)

- **Anthropic Academy 연동** — Claude 101, Claude Code in Action, MCP 과정, AI Fluency, Agent Skills 등 13개 무료 수료증 과정을 본문 곳곳에 연결
- **인터랙티브 객관식 퀴즈** — 6개 채점 퀴즈(총 21문항)로 텍스트 영역 평가를 대체하고 즉시 피드백·점수 제공
- **XP와 게이미피케이션** — 일차·퀴즈 완료 시 XP 획득, Novice에서 Master까지 레벨업, 업적 배지 6종
- **일일 연속 학습** — 매일 방문해 연속 일수를 쌓고, 3일 연속 시 배지 해제
- **신제품 반영** — Claude Code, Claude Cowork(2026년 1월), Agent Skills, MCP 업데이트

## 🤖 googleadsagent.ai 연결 고리

[googleadsagent.ai](https://googleadsagent.ai)는 **살아 있는 참조 구현**으로 전 과정에 녹아 있습니다.

| 구성 요소 | 구현 | 일차 |

| 두뇌 | Anthropic의 Claude(Opus 4.5 + Sonnet 4.5) | 1 |
| 도구 | Google Ads API에 실시간 연결된 Python API actions 28개 | 2 |
| MCP | 어댑터 계층: `tool_executor.py` | 2 |
| 컨텍스트 | CEP 프로토콜 + Session State Manager | 3 |
| 품질 | Top-Down Reporting + CONFIRM 쓰기 안전 | 4 |
| 멀티 에이전트 | 🦁 Simba · 🐠 Nemo · ❄️ Elsa · 🧞 Aladdin · 🌊 Moana · 🤖 Baymax | 5 |
| 프로덕션 | CLI, REST API, Docker, Python SDK | 5 |

## 🎓 Anthropic Academy — 무료 강의

13개 과정은 모두 [Anthropic Academy (Skilljar)](https://anthropic.skilljar.com/)에서 무료이며 수료증을 받을 수 있습니다.

| 과정 | 초점 | 수준 |
|--------|-------|--------|
| **[Claude Code in Action](https://anthropic.skilljar.com/claude-code-in-action)** | AI 코딩 어시스턴트, GitHub, MCP 서버, hooks, SDK | Intermediate |
| **[Claude 101](https://anthropic.skilljar.com/claude-101)** | Chat, Cowork, Code 모드, Projects, Artifacts, Skills | Beginner |
| **AI Fluency: Framework & Foundations** | 네 가지 D — Delegation, Description, Discernment, Diligence | 전 수준 |
| **Building with the Claude API** | API 호출, 스트리밍, function calling, 구조화 출력 | Developer |
| **Intro to Model Context Protocol** | Python의 MCP 서버/클라이언트, tools, resources, prompts | Developer |
| **MCP: Advanced Topics** | Sampling, 알림, 파일 시스템, 전송 방식 | Advanced |
| **Introduction to Agent Skills** | Claude Code에서 `SKILL.md` 워크플로 만들기·공유 | Developer |
| **AI Fluency for Educators** | 교육과 기관 전략에서의 AI Fluency | Educators |
| **AI Fluency for Students** | 학습과 커리어를 위한 AI 역량 | Students |
| **AI Fluency for Nonprofits** | 미션 중심 조직을 위한 AI Fluency | Nonprofits |
| **Teaching AI Fluency** | 강사 주도 환경에서 AI Fluency 가르치기·평가 | Instructors |
| **Claude with Amazon Bedrock** | AWS의 Anthropic 모델 | Cloud |
| **Claude with Google Cloud Vertex AI** | Google Cloud의 Anthropic 모델 | Cloud |
