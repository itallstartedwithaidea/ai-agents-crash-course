# 🎮 Capstone: AI-Powered Game Master RPG

> The complete agentic system — brain, tools, memory, multi-step reasoning, orchestration

```
Build an AI-powered text RPG Game Master as a single HTML file. Requirements:
- Character creation: name, class (Warrior/Mage/Rogue)
- Persistent stats: HP, Attack, Defense, Magic, Level, XP
- Inventory system with equippable items and consumables
- Turn-based combat with enemy AI and attack patterns
- Narrative that adapts to player choices (3+ branching points)
- Shop between encounters for purchasing equipment
- Boss encounter requiring strategic decision-making
- Visual HP bars, atmospheric dark-fantasy styling
- Save/load game state
```

### Why This Is Agentic

This game implements every course concept:

| Concept | Implementation |
|---------|---------------|
| **Brain** | Game AI reasoning about choices |
| **Tools** | Combat calculator, inventory manager, story engine |
| **Memory** | Character state, story progress, inventory persistence |
| **Orchestration** | Managing combat, story, inventory, and shop systems simultaneously |
| **Quality** | Balanced difficulty, consistent rules, fair encounters |

This is the same architecture as googleadsagent.ai — just applied to games instead of advertising.
