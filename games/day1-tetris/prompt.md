# 🎮 Day 1: Tetris

> Copy → Paste into [Claude](https://claude.ai), [ChatGPT](https://chatgpt.com), or [Cursor](https://cursor.com) → Play

```
Build a fully playable Tetris game as a single HTML file with inline CSS and JavaScript. Requirements:
- Classic Tetris rules: 7 tetromino pieces, rotation, line clearing
- Arrow keys to move/rotate, spacebar for hard drop
- Score display, next piece preview, level progression
- Game over detection with restart capability
- Dark background with colorful pieces and smooth animations
- Ghost piece indicating landing position
Optimize for a polished arcade experience.
```

**Controls:** ← → move · ↑ rotate · ↓ soft drop · Space hard drop

**Iterate:** "Add hold piece (C key)" · "Neon colors" · "Add music" · "Touch controls for mobile"
