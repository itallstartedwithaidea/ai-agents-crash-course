# 🎮 Day 5: Duck Hunt

> Copy → Paste into [Claude](https://claude.ai) or [Cursor](https://cursor.com) → Play

```
Build a Duck Hunt-style shooting gallery as a single HTML file. Requirements:
- Click or tap to shoot at flying ducks
- Ducks enter from sides with randomized flight patterns
- Crosshair cursor replaces default mouse pointer
- Gunshot sound and muzzle flash via Web Audio API
- Hit ducks tumble with falling animation
- Hunting dog at bottom retrieves fallen ducks
- Round system: 10 ducks per round, 3 rounds, increasing difficulty
- Ammo limit: 3 shots per duck
- Score display and accuracy percentage
- Classic NES aesthetic
```

**Controls:** Mouse aim · Click shoot

**Iterate:** "Add clay pigeon bonus round" · "Add combo multiplier" · "Dog animations based on accuracy"
