# 🎮 Day 2: Zelda-Style Adventure

> Copy → Paste into [Claude](https://claude.ai) or [Cursor](https://cursor.com) → Play

```
Build a Zelda-style top-down adventure game as a single HTML file. Requirements:
- Player character controlled by arrow keys or WASD
- Overworld map: grass, collidable trees, impassable water, paths
- Three or more enemy types with movement patterns and damage
- Sword attack on spacebar with visible swing animation
- Health system (3 hearts), collectible rupees and health pickups
- Multiple connected rooms with edge-of-screen transitions
- Mini-map overlay showing explored rooms
- SNES-era pixel-art aesthetic with green overworld palette
```

**Controls:** Arrows/WASD move · Space sword

**Iterate:** "Add boss in room 3" · "Add bow (B key)" · "Add shop" · "Add dungeon with lantern"
