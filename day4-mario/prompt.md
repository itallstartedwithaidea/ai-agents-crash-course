# 🎮 Day 4: Super Mario Bros

> Copy → Paste into [Claude](https://claude.ai) or [Cursor](https://cursor.com) → Play

```
Build a Super Mario Bros-style platformer as a single HTML file. Requirements:
- Side-scrolling with controllable character
- Arrow keys for movement, spacebar or up-arrow to jump
- Platforms, pipes, brick blocks, question-mark blocks
- Breakable blocks yield coins when hit from below
- Two or more enemy types; jump on enemies to defeat them
- Coin counter, score display, pit death, 3-life system
- Flag pole to complete the level
- Authentic NES-era physics: momentum, gravity, acceleration
```

**Controls:** ← → move · Space/↑ jump

**Iterate:** "Add mushroom power-up" · "Add fireball" · "Add level 2 underground" · "Moving platforms"
